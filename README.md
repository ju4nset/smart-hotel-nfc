# Smart Hotel NFC

Projeto que estou desenvolvendo para praticar Java, Spring Boot e outras ferramentas de integração, como Mercado Pago, Google e outras ferramentas de back-end.

## O que já foi feito

- Cadastro de hóspedes
- Cadastro de reservas
- Cadastro de quartos
- Verificação de conflito entre datas
- Integração de pagamento com o Mercado Pago
- Atualização de pagamento por webhook

## Linguagem de programação e ferramentas que estou usando nesse projeto

- Java
- Spring Boot
- MySQL
- Git e GitHub
- Gemini e GPT
- Notion

  ## INTEGRAÇÃO COM ASAAS
- Crianção de clientes pela API do Asaas
- Crianção dos DTOs o retorno e envio dos dados
- Crianção da classe AsaasService
- Endpoint post
- E o retorno do customerId que é gerado pelo Asaas

  ## Próximo passo para a integração com o Asaas

  - Buscar por CNPJ E CPF

  - E receber os status de pagamento via webhook

## Sobre o Projeto

 O projeto está em desenvolvimento. O objetivo inicial é o aprendizado, conseguir entender bem como funciona a estrutura de um projeto, conseguir aprender sobre Java e Spring Boot, que são áreas que tenho preferência, como back-end, mas a ideia final é tornar esse projeto realmente um negócio que possa vir a ser uma ferramenta útil na hotelaria.

 ## Informações adicionais 
 O projeto ainda esta com o modelo de pagamento do mercado pago para não haver problemas com o funcionamento dele, mas logo estará sendo atualizado para funcionar apenas com o Asaas e outras funcionalidades específica do gestor PMS
